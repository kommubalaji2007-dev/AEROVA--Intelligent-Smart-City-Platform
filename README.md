AEROVA — Intelligent Smart City Platform
A complete front-end smart-city control center inspired by desktop operating-system interfaces.
Features
Login screen
Desktop-style control center
Collapsible sidebar
City Home dashboard
Interactive simulated digital city map
Traffic, Energy, Water, Waste, Transport and Safety modules
AI Center with chat-style assistant and prediction models
Analytics dashboard
Notifications
Settings
Multiple draggable windows
Toast notifications
Traffic/energy/water/waste simulations
Text report export
Responsive layout
No external libraries required
Run
Extract the ZIP.
Open the folder in VS Code.
Open index.html in a browser.
Recommended VS Code option:
Install the "Live Server" extension.
Right-click index.html.
Choose "Open with Live Server".

Important
This is a front-end prototype/simulation. The AI, sensors, traffic data, IoT values and city map are simulated in JavaScript. A production system would connect these modules to a real backend, database, authentication service, GIS/map provider and IoT devices.
